Starting point

The base is GitHub main, b9079592f2ddbfaf24f2fb18b6b09d2ae58f7a9b.
Its full source tree was checked against the local starting tree before any
Gate 4 changes. The research notes were committed before implementation.
The old catalog-expansion branch was not used as this version's base.

What changed

Five real cashback products now have fixed IDs 101-105, earning rules,
restrictions, fee notes, source links and a check date. The original sample
IDs, records and reward function are preserved for the earlier gates.

The console has a --gate4 mode. The same Windows wallet view has a Gate 4
mode and a purchase form. Both views use the same comparison function.
The existing add/remove/save/reload code handles the new IDs too. The default
real-card save is separate so an old practice wallet does not change meaning.

New money input reads exact whole cents. Date input checks month lengths and
leap years. Calculations use total category rates, split capped spending,
show conditional ranges when cap use is unknown, and list all rounded ties.
Booking services stay separate. A dated Lyft rule expires at its boundary.
Benefit notes describe enrollment, paid renewal and deadlines; they are not
silently added to cashback as money.

Problems found and checked again

The first MinGW build could not use the old timer's timespec_get. The Windows
timer now uses GetTickCount64; the other build keeps the C11 timespec timer.
An explicitly wide cursor resource also avoids depending on a compiler's
default Unicode macro. The rebuilt Windows program passed compilation.

Two original Linux tests expected the previous unsupported-window wording.
The message now matches that expectation; both complete old suites passed
again. This was a wording mismatch, not evidence that Windows ran.

During review, comparison input was also changed to preserve the difference
between ordinary end of input and a real read error, as the older menu does.
The final complete suites and sanitizer run use that version.
